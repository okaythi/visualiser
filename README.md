# visualiser

Audio stems visualiser for `visualiser.nixlabs.tech`.

Built with Cloudflare Pages, React 18, Vite, and strict TypeScript.

## Design Rules & Brand Guidelines

> **IMPORTANT**: All visual design and styling for this repository must strictly adhere to [`BRAND_GUIDELINES.md`](./BRAND_GUIDELINES.md).

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
